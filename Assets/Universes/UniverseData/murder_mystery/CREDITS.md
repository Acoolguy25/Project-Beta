# Murder Mystery credits

## Sounds (`Audio/`)

All by Kenney (www.kenney.nl), released under CC0 1.0 (public domain,
https://creativecommons.org/publicdomain/zero/1.0/). Crediting is optional; we do it anyway.
kenney.nl is not reachable from the cloud environment, so the files were taken from the GitHub mirror
github.com/ETdoFresh/kenney.nl (license files included in the mirror). Files were renamed for what they do.

| File | Kenney pack | Original file |
|---|---|---|
| role_reveal.ogg | Music Jingles | Pizzicato jingles/jingles_PIZZI07.ogg |
| kill_sting.ogg | Music Jingles | Hit jingles/jingles_HIT15.ogg |

Also used, from elsewhere in the project: the horn when the sheriff goes down (`classic_horror/Flooded_Grounds/Content/Sounds/Horn.mp3`),
and the shared game-feel kit's cues (see `Packages/com.ryan.gameframework/Runtime/GameFeel/Audio/CREDITS.md`).

## Icons

HUD icons come from the shared theme (`Packages/com.ryan.ui/Runtime/UI/Theme/GameIcons/CREDITS.md`).

## Models

The standing lamp (`Prefabs/MM_StandingLamp.prefab`) and its corner (`Prefabs/MM_LampCorner.prefab`) use
`lamp_standing.fbx`, `armchair_pillows.fbx`, `cabinet_medium_decorated.fbx` and `rug_oval_A.fbx` from **KayKit Furniture Bits 1.0**
by Kay Lousberg (www.kaylousberg.com), CC0 1.0, already in the project at `Assets/ThirdParty/KayKit/FurnitureBits/`
(license in that folder). Its glowing shade material `Materials/MM_LampGlow.mat` is a copy of the pack's material
with emission added.

The thrown knife (`Prefabs/MM_ThrownKnife.prefab`) reuses the murderers' dagger model,
`RoughDagger02_Red` from the One-Handed Melee Weapons Lite pack already in the game framework
(`Packages/com.ryan.gameframework/Runtime/Tools/Melees/One-Handed Melee Weapons Lite/`).
