# Murder Mystery credits

## Sounds (`Audio/`)

All by Kenney (www.kenney.nl), released under CC0 1.0 (public domain,
https://creativecommons.org/publicdomain/zero/1.0/). Crediting is optional; we do it anyway.
kenney.nl is not reachable from the cloud environment, so the files were taken from the GitHub mirror
github.com/ETdoFresh/kenney.nl (license files included in the mirror). Files were renamed for what they do.

| File | Kenney pack | Original file |
|---|---|---|
| gavel_1..3.ogg | Impact Sounds | impactWood_heavy_000..002.ogg |
| drum_1..5.ogg | Impact Sounds | impactSoft_heavy_000..004.ogg |
| bell_toll.ogg | Impact Sounds | impactBell_heavy_000.ogg |
| role_reveal.ogg | Music Jingles | Pizzicato jingles/jingles_PIZZI07.ogg |
| kill_sting.ogg | Music Jingles | Hit jingles/jingles_HIT15.ogg |

Also used, from elsewhere in the project: the meeting horn (`classic_horror/Flooded_Grounds/Content/Sounds/Horn.mp3`),
and the shared game-feel kit's cues (see `Packages/com.ryan.gameframework/Runtime/GameFeel/Audio/CREDITS.md`).
