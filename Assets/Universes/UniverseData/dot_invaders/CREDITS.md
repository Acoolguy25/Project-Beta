# Dot Invaders credits

## Sounds (`Client/Audio`)

All by Kenney (www.kenney.nl), from the **Digital Audio** pack, released under CC0 1.0 (public
domain, https://creativecommons.org/publicdomain/zero/1.0/). Crediting is optional; we do it anyway.
kenney.nl is not reachable from the cloud environment, so the files were taken from the GitHub
mirror github.com/ETdoFresh/kenney.nl (`kenney_digitalaudio`, license file included there).

| File | Original file | Used for |
|---|---|---|
| di_send_1.ogg, di_send_2.ogg, di_send_3.ogg | pepSound1.ogg, pepSound2.ogg, pepSound3.ogg | order blip (pitched by wave size) |
| di_capture.ogg | threeTone1.ogg | your team captures a base |
| di_base_lost.ogg | lowDown.ogg | your team loses a base |
| di_clash_1.ogg, di_clash_2.ogg | zap1.ogg, zap2.ogg | troops clash on a road |
| di_elimination.ogg | zapThreeToneDown.ogg | a team is eliminated |

Win and lose stings, sparks, rings, confetti and camera shake come from the shared game feel kit
(`Packages/com.ryan.gameframework/Runtime/GameFeel`, see its `Audio/CREDITS.md`).
