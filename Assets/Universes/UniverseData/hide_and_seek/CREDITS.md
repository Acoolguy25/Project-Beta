# Hide and Seek credits

Map props: KayKit Furniture Bits, Restaurant Bits and Halloween Bits by Kay Lousberg (CC0 1.0), and
Poly Haven textures (CC0 1.0); see the project's `credits.md` for the full list.

## Sounds (`Audio/`)

Kenney sounds are by Kenney (www.kenney.nl), released under CC0 1.0 (public domain,
https://creativecommons.org/publicdomain/zero/1.0/). kenney.nl is not reachable from the cloud
environment, so they were taken from the GitHub mirror github.com/ETdoFresh/kenney.nl (license files
included there). Files were renamed for the job they do.

| File | Source | Original file |
|---|---|---|
| creak_1..3.ogg | Kenney, RPG Audio | creak1.ogg, creak2.ogg, creak3.ogg |
| door_creak_1..2.ogg | Kenney, RPG Audio | doorOpen_1.ogg, doorOpen_2.ogg |
| tick.ogg | Kenney, Interface Sounds | tick_004.ogg |
| sting_tag.ogg | Kenney, Music Jingles | Hit jingles/jingles_HIT11.ogg |
| sting_last_hider.ogg | Kenney, Music Jingles | Hit jingles/jingles_HIT15.ogg |
| voice_hurry_up.ogg | Kenney, Voiceover Pack | Male/hurry_up.ogg |
| seeker_step_1..5.ogg | Kenney, Impact Sounds | footstep_wood_000..004.ogg |
| clock_loop.ogg | Made for this game from Kenney Interface Sounds tick_004.ogg (tick and a lowered tock once a second, with a short wooden resonance) | CC0 1.0 |
| heartbeat.ogg | Synthesized for this game (two pitched low thumps) | CC0 1.0 |
| wind_loop.ogg | Synthesized for this game (filtered noise with slow gusts, crossfaded into a seamless 16 s loop) | CC0 1.0 |
| taunt_1..3.ogg | Synthesized for this game (two- and three-note slide whistles) | CC0 1.0 |

The game also plays the shared game feel kit's sounds (whoosh, alarm, countdown beep, go, win, lose);
those are credited in `Packages/com.ryan.gameframework/Runtime/GameFeel/Audio/CREDITS.md`.
